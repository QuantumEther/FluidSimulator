# SI performance milestone downloads

These exports preserve the tested simulation at commit `7c0a9f4dd514c9e7b89d2543fff9b004be0a513c`, tagged `milestone-si-performance`.

- `FluidSimulator-preview.html`: self-contained simulator modules, CSS and shaders. Download the raw file and open it in a current WebGPU-capable Chrome or Edge browser. Tailwind and Google Fonts remain external presentation assets.

The HTML was checked with Chromium/Vulkan SwiftShader and started with 320 particles without captured page or WebGPU errors. The source package matches the tagged source files. Hardware speed and full scientific calibration remain unverified; see the project's performance notes.

These are versioned exports. They are not regenerated automatically when the simulator changes.
